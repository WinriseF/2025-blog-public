# Frontend Runtime

## Purpose

Owns the shared layout, time theme, navigation, atmosphere, homepage behavior, calendar, and visible-animation performance.

## Key Paths

| Path | Use it for |
| --- | --- |

| `src/layout/index.tsx` | Providers, atmosphere, global navigation, mobile scroll-top, homepage fitting. |

| `src/app/world-clock/` | Interactive Earth, location time readings, annual solar track, and responsive scene layout. |

## Main Flow

`layout.tsx` injects configuration and wraps every route in the client `Layout`. The client layout mounts providers, atmosphere, navigation, and route-specific exceptions. Navigation keeps the compact appearance picker; the homepage uses one animated quick-controls card for direct theme selection, the persisted click-effect preference, and E/V/N deployment navigation from `site-content.json`. Theme changes continue to use the original View Transition flow. Continuous visuals use the shared animation loop; the homepage WebGL core targets a constant 60 FPS with capped DPR, while click feedback uses a bounded pool of local canvases that is idle when no effect is visible.

Playback request IDs prevent stale play promises from overwriting newer selections or a pause. No audio loads until playback is requested; failures require an explicit retry or another track. The music UI uses existing time-theme variables and reduced-motion rules, without synthetic equalizer or record animations.

- Do not add idle frame loops, raw scroll work, or layout reads in pointer-move handlers.
- Browser constructor mocks in lifecycle tests must use a normal function or class with `vi.fn`; arrow-function implementations cannot be constructed by current Vitest. Keep the observer visibility and cleanup assertions intact.
- The homepage WebGL core is the planet-only Orbitalis scene. `src/app/(home)/animated-core.tsx` owns the poster, visibility-triggered import, and pointer input; `orbitalis-scene.ts` owns the original mesh/UVs, AgX lighting, thin atmosphere, progressive texture blend, and GPU cleanup. Do not load the station, original 16K GLB chunks, or a fixed 4K drawing buffer on the homepage.
- Keep the planet canvas, poster, and inner button background transparent. `hi-card.tsx` inherits the shared glass card surface and theme border, uses theme text/accent colors, and adds only a subtle lower fade into `--color-card`. Greeting shadows use `--color-bg`. Do not reintroduce an opaque black/navy stage or fixed white labels across the four themes.
- `orbitalis-assets.ts` resolves versioned assets through `getAssetUrl()` and the image CDN: the texture-free GLB, 1K WebP preview, 4K AVIF (quality 85, 4:4:4), and planet-only WebP poster live exclusively in sibling `2025-blog-img/images/project/orbitalis/`. Keep matching URL paths; do not copy or commit these assets under this repository's `public/` directory. The image repository's `edgeone.json` gives this directory CORS access and immutable caching; its TinyPNG collector excludes this pre-encoded directory so published bytes remain stable. Publish these assets and headers before deploying the frontend. Keep glTF texture orientation (`flipY = false`) and sRGB color handling. Bump asset filenames when changing their contents.
- Render the 1K sphere first, then request the 4K texture at low priority and blend both color and emission over 450 ms. Keep the preview if detail loading fails; keep the static poster if WebGL or initial loading fails. The scene's AbortSignal is the single unmount teardown trigger; release ImageBitmaps, textures, geometry, materials, observers, and the renderer on unmount/context loss, including resources that finish loading after cancellation. Dispose the preview after the blend completes.
- The planet targets 60 FPS in idle, hover, and activation states. Reduced motion keeps the pose static and changes texture quality immediately, but still draws at 60 FPS as explicitly requested; hidden/offscreen loops remain paused. Preserve antialiasing and the container-based DPR cap (1 below 640px, otherwise 1.25). Always redraw after resizing. Read pointer bounds on entry, not in pointer-move handlers.
- Clicking or keyboard activation triggers a visible scale pulse: the activation target adds 39%, with a faster attack (24/s), gentler release (10/s), and activation decay (3/s), producing a peak near 30% before returning to the hover/idle size. Keep this scale response separate from the slower pointer-position easing; a small scale target combined with slow smoothing made the previous feedback imperceptible.
- The same activation restarts a damped left/right sway at 18 radians/s, combining a 0.1-unit lateral offset with small yaw/roll rotations. Its amplitude follows activation decay and returns to the normal pose. Smooth pointer-follow offsets remain separate (0.14 horizontal, 0.06 vertical), so the sphere follows mouse movement without accumulating sway drift. Use loop delta time so hidden/offscreen pauses preserve motion continuity; reduced motion keeps these effects static.
- Five homepage core clicks within a rolling 1500 ms window navigate to `/orbitalis`; ordinary clicks retain the scale/sway response. Do not preload station or high-resolution observatory assets on the homepage. Touch manipulation prevents double-tap zoom from intercepting this entry gesture.
- `/orbitalis` adapts the original MIT-licensed Orbitalis scene, camera, dedicated station lighting, depth-preserving render passes, orbital drag, optical zoom, pan, and independent ring rotor. The client owns UI and teardown, `lunar-controller.ts` owns gestures/scheduling, `lunar-scene.ts` owns GPU resources, and the station motion/drag modules preserve authored transforms and occlusion. Consume typed drag results directly; numerical validity belongs in the projection code. Drawing-buffer limits remain local to the scene rather than unused React diagnostics. The shared shell hides navigation, atmosphere, click effects and the floating music player on this immersive route; existing audio playback continues. Rendering follows viewport DPR up to 1.5 and a 3840px long-edge cap; paused scenes draw only on changes, and hidden scenes stop rendering.
- Homepage and observatory atmosphere materials share `src/lib/orbitalis-atmosphere.ts`; each scene retains its light, tint, radius, and local resource ownership.
- Keep observatory controls in a compact top-right cluster: quality and help on the first row, rotation/reset/zoom on the second, with small status text below. Icon controls retain accessible labels, titles and 32px targets; interaction help expands only on request. - Observatory resources live only in `2025-blog-img/images/project/orbitalis/` behind the existing CORS/immutable headers. `observatory-scene-v2.json` references the shared texture-free planet mesh, unchanged station chunks, background/poster, and four separate texture levels. Start with 1K and request 4K by default; fetch 8K or 16K only on selection. The native 16K tier is 15360 x 7680; its v2 AVIF chunks contain exactly 11,059,879 bytes each and reassemble to the unchanged image SHA-256. Split AVIF files are byte ranges of one encoded image reassembled into a Blob, not GLB texture chunks. Publish new versioned chunks and manifest before the frontend references them; leave existing immutable asset URLs intact for cached pages.
- The observatory loading/fallback preview fits the complete 4:3 poster inside the viewport over a dimmed, full-viewport cover of the existing starfield. - `texture-control.ts` reuses the pending promise when the requested quality is already loading, while selecting another quality aborts the superseded request. Keep completed compressed Blobs for all four quality levels in the mounted scene (about 35.5 MB total), so switching back avoids network requests even with the browser cache disabled; clear this cache on scene disposal and evict a level on decode/dimension failure. Retain only the active decoded bitmap/GPU texture; check the request's aborted signal after decoding and clear pending state only if that controller is still current. Check device limits, keep the previous texture on failure, and wake a paused scene after successful selection. Disable unsupported tiers rather than silently resizing them. Bump versioned asset names when their bytes change.
- Keep shared homepage card tilt (`src/components/card.tsx`) on Motion's spring and preserve backdrop blur throughout interaction. `will-change` is a Motion value enabled for hover, entrance/scale transitions, and tilt spring motion; release it after settling. Cache glow gradients as shared 512px textures per theme effect; resize reuses these textures and cleanup releases them. Preserve glow colors, alpha stops, and compositing; calibrate drift with `deltaMs * atmosphere.targetFps / 1000`. Theme frame budgets remain 6/6/8/5 FPS. On-demand wake calls and redundant visibility notifications leave pending timing intact; stopped/hidden loops reset timing. `tests/animation/animation-loop.test.ts` models timers and 60/120/144/165 Hz displays, target changes, wake calls, and hidden recovery. A target is a scheduling budget, not a guarantee under GPU load or a display below 60 Hz.
